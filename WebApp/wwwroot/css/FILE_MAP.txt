📁 CSS DIRECTORY STRUCTURE & FILE MAP

This file maps the complete CSS architecture created for the project.

═══════════════════════════════════════════════════════════════════════════════

📂 wwwroot/css/
│
├─ 🔗 index.css ⭐ MASTER STYLESHEET
│  └─ Import entry point (add ONLY this to _Layout.cshtml)
│  └─ Imports all 5 layers in correct order
│  └─ ~50 lines (mostly import statements)
│
├─ 🎨 layout.css 
│  └─ Structural elements: navbar, containers, grids
│  └─ Page sections: dashboard-header, bill-info, godown-section
│  └─ Responsive design: @media (max-width: 991px) breakpoints
│  └─ ~200 lines
│
├─ 🛠️ utilities.css
│  └─ Helper classes: spacing, text, display, flex
│  └─ Margin: m-0, mb-2, mb-3, mt-1, mt-3, me-2
│  └─ Padding: p-0, px-2, py-2
│  └─ Text: text-muted, text-secondary, text-accent, fw-600, etc.
│  └─ Display: d-flex, d-grid, d-none, d-block
│  └─ Flex: flex-between, flex-center, gap-2, gap-3
│  └─ Print: hidden-print (shows normally, hides on print)
│  └─ Opacity, borders, width helpers
│  └─ ~150 lines
│
├─ 🖨️ print.css
│  └─ Print media queries: @media print { ... }
│  └─ Hides: navbar, print button, action buttons
│  └─ Sets: white background, black text, page margins
│  └─ Optimizes: layout for paper/PDF export
│  └─ ~100 lines
│
├─📂 themes/
│  │
│  └─ 🎭 theme-dark.css
│     └─ CSS variables for entire application
│     └─ 30+ color variables (accent, background, text, border)
│     └─ Root configuration: font-family, defaults
│     └─ ~80 lines
│     └─ (Optional future: theme-light.css, theme-custom.css)
│
└─📂 components/
   │
   ├─ 📊 tables.css
   │  └─ Table styling: .packing-table
   │  └─ Header row: thead th styling
   │  └─ Body rows: hover effect, border
   │  └─ Cell classes: sl-no, item-name, stock-info, checkbox-cell
   │  └─ States: packed-item (opacity 0.55)
   │  └─ ~80 lines
   │
   ├─ 🔘 buttons.css
   │  └─ Base: .btn (flex, padding, transition)
   │  └─ Variants: primary, secondary, print, success, danger, warning
   │  └─ Special: icon-only buttons (.btn-icon)
   │  └─ Groups: .btn-group for button collections
   │  └─ States: hover (opacity, transform), active, disabled
   │  └─ ~140 lines
   │
   ├─ 📝 controls.css
   │  └─ Form groups: .form-group layout
   │  └─ Inputs: input, select, textarea styling
   │  └─ Alerts: 4 types (warning, success, danger, info)
   │  └─ Validation: is-invalid, is-valid, feedback text
   │  └─ Checkboxes & radio buttons: sizing, accent color
   │  └─ Help text: .form-text (small, muted)
   │  └─ Dark theme alert colors
   │  └─ ~180 lines
   │
   └─ 📋 aggrid.css
	  └─ AG Grid customization
	  └─ Header styling, cell padding
	  └─ Row hover effects
	  └─ Selection: checkbox styling
	  └─ Pagination: footer styling
	  └─ Filter menu: visibility and styling
	  └─ Overlay: no data, loading states
	  └─ ~120 lines

🚀 HOW TO USE

1. Include master stylesheet in _Layout.cshtml:
   <link rel="stylesheet" href="~/css/index.css" asp-append-version="true" />

2. Use class-based styling in Razor views:
   <div class="packing-dashboard mb-3">
	   <h3 class="fw-600">Title</h3>
	   <button class="btn btn-primary">Action</button>
   </div>

3. Add new styles:
   - Edit appropriate .css file in the layer system
   - Use CSS variables from theme-dark.css
   - Reference in Razor using class names

4. Test & deploy:
   - Run build (F6)
   - Test in browser
   - Test print (Ctrl+P)
   - Test responsive (F12, mobile view)
